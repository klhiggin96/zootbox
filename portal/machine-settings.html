ADB Port Forwarding Setup

To connect to a tablet backend via USB:

  1. Connect tablet via USB cable
  2. Run: adb devices (verify connection)
  3. Run: adb forward tcp:8080 tcp:8080
  4. Use endpoint URL: http://localhost:8080
